LangGraph provides two ways to define agent workflows:

<CardGroup cols={2}>
  <Card title="Graph API" icon="diagram-project">
    Build agents as explicit state graphs using `StateGraph`, `add_node`, and `add_edge`. `create_react_agent` from `langgraph.prebuilt` uses the Graph API.
  </Card>
  <Card title="Functional API" icon="function">
    Define workflows as plain Python functions decorated with `@entrypoint` and `@task` from `langgraph.func`. No graph construction required.
  </Card>
</CardGroup>

`create_supervisor()` works with both. Any `Pregel` object — the common runtime interface used by both compiled `StateGraph` graphs and `@entrypoint` workflows — can be passed as an agent.

## The `@entrypoint` and `@task` decorators

- **`@task`** — Wraps a function as an async-compatible unit of work. Results are accessed via `.result()`.
- **`@entrypoint()`** — Marks the outer function as the entry point of the workflow. It receives the full state dict and must return a state update dict.

## Requirement: set a `.name` attribute

Every agent passed to `create_supervisor` must have a non-`None`, non-`"LangGraph"` name. For Graph API agents you set this via `create_react_agent(..., name=...)` or `.compile(name=...)`. For Functional API agents, you must **manually set the `.name` attribute** on the `@entrypoint` function after defining it:

```python
@entrypoint()
def joke_agent(state):
    ...

joke_agent.name = "joke_agent"
```

<Warning>
  If you forget to set `.name` on a Functional API agent, `create_supervisor` will raise a `ValueError` asking you to provide a name.
</Warning>

## Mixing Functional API and Graph API agents

You can freely mix agents built with the Functional API and the Graph API in the same supervisor.

```python
from langgraph.prebuilt import create_react_agent
from langgraph_supervisor import create_supervisor

from langchain_openai import ChatOpenAI

from langgraph.func import entrypoint, task
from langgraph.graph import add_messages

model = ChatOpenAI(model="gpt-4o")

# --- Functional API agent ---

@task
def generate_joke(messages):
    """First LLM call to generate initial joke"""
    system_message = {
        "role": "system",
        "content": "Write a short joke"
    }
    msg = model.invoke(
        [system_message] + messages
    )
    return msg

@entrypoint()
def joke_agent(state):
    joke = generate_joke(state['messages']).result()
    messages = add_messages(state["messages"], [joke])
    return {"messages": messages}

# Required: set the name so create_supervisor can identify this agent
joke_agent.name = "joke_agent"

# --- Graph API agent ---

def web_search(query: str) -> str:
    """Search the web for information."""
    return (
        "Here are the headcounts for each of the FAANG companies in 2024:\n"
        "1. **Facebook (Meta)**: 67,317 employees.\n"
        "2. **Apple**: 164,000 employees.\n"
        "3. **Amazon**: 1,551,000 employees.\n"
        "4. **Netflix**: 14,000 employees.\n"
        "5. **Google (Alphabet)**: 181,269 employees."
    )

research_agent = create_react_agent(
    model=model,
    tools=[web_search],
    name="research_expert",
    prompt="You are a world class researcher with access to web search. Do not do any math."
)

# --- Supervisor ---

workflow = create_supervisor(
    [research_agent, joke_agent],
    model=model,
    prompt=(
        "You are a team supervisor managing a research expert and a joke expert. "
        "For current events, use research_agent. "
        "For any jokes, use joke_agent."
    )
)

app = workflow.compile()
result = app.invoke({
    "messages": [
        {
            "role": "user",
            "content": "Share a joke to relax and start vibe coding for my next project idea."
        }
    ]
})

for m in result["messages"]:
    m.pretty_print()
```

## When to use each API

| | Graph API | Functional API |
|---|---|---|
| **Style** | Declarative graph construction | Imperative Python functions |
| **Best for** | Complex branching, cycles, conditional edges | Linear or lightly branched workflows |
| **Name assignment** | `create_react_agent(..., name=...)` or `.compile(name=...)` | Manual: `agent.name = "..."` |
| **Prebuilt support** | `create_react_agent`, tool nodes, etc. | Any Python logic |

<Tip>
  If your Functional API agent needs checkpointing or a store, pass them to `workflow.compile()` on the outer supervisor graph. The supervisor handles persistence at the top level.
</Tip>

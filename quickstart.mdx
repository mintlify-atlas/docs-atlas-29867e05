This guide walks you through creating a supervisor that coordinates two specialized agents — a math expert and a research expert — to answer a question that requires both capabilities.

<Note>
  LangGraph Supervisor requires **Python >= 3.10**.
</Note>

<Steps>

<Step title="Install the packages">

Install `langgraph-supervisor` and the OpenAI integration for LangChain:

<CodeGroup>

```bash pip
pip install langgraph-supervisor langchain-openai
```

```bash uv
uv add langgraph-supervisor langchain-openai
```

</CodeGroup>

</Step>

<Step title="Set your API key">

Export your OpenAI API key as an environment variable:

```bash
export OPENAI_API_KEY=<your_api_key>
```

<Tip>
  For debugging and tracing your agents during development, set up [LangSmith](https://docs.langchain.com/langsmith/home) by exporting `LANGCHAIN_API_KEY` and `LANGCHAIN_TRACING_V2=true`.
</Tip>

</Step>

<Step title="Create the specialized agents">

Define tool functions and use `create_react_agent` from LangGraph to create two agents — one for math and one for research. Each agent must be given a unique `name`.

```python
from langchain_openai import ChatOpenAI
from langgraph.prebuilt import create_react_agent

model = ChatOpenAI(model="gpt-4o")

def add(a: float, b: float) -> float:
    """Add two numbers."""
    return a + b

def multiply(a: float, b: float) -> float:
    """Multiply two numbers."""
    return a * b

def web_search(query: str) -> str:
    """Search the web for information."""
    return (
        "Here are the headcounts for each of the FAANG companies in 2024:\n"
        "1. **Facebook (Meta)**: 67,317 employees.\n"
        "2. **Apple**: 164,000 employees.\n"
        "3. **Amazon**: 1,551,000 employees.\n"
        "4. **Netflix**: 14,000 employees.\n"
        "5. **Google (Alphabet)**: 181,269 employees."
    )

math_agent = create_react_agent(
    model=model,
    tools=[add, multiply],
    name="math_expert",
    prompt="You are a math expert. Always use one tool at a time."
)

research_agent = create_react_agent(
    model=model,
    tools=[web_search],
    name="research_expert",
    prompt="You are a world class researcher with access to web search. Do not do any math."
)
```

</Step>

<Step title="Create the supervisor">

Pass the agents to `create_supervisor` along with a model and an optional prompt that tells the supervisor how to delegate tasks:

```python
from langgraph_supervisor import create_supervisor

workflow = create_supervisor(
    [research_agent, math_agent],
    model=model,
    prompt=(
        "You are a team supervisor managing a research expert and a math expert. "
        "For current events, use research_agent. "
        "For math problems, use math_agent."
    )
)
```

`create_supervisor` returns a `StateGraph`. You must compile it before invoking.

</Step>

<Step title="Compile and invoke">

Compile the workflow and invoke it with a user message:

```python
app = workflow.compile()

result = app.invoke({
    "messages": [
        {
            "role": "user",
            "content": "what's the combined headcount of the FAANG companies in 2024?"
        }
    ]
})
```

To print each message in the result:

```python
for m in result["messages"]:
    m.pretty_print()
```

</Step>

</Steps>

## What happens at runtime

When you invoke the workflow, the supervisor:

1. Receives the user message.
2. Calls `transfer_to_research_expert` to delegate the lookup task.
3. The research agent runs `web_search` and returns the headcount data.
4. Control returns to the supervisor, which then calls `transfer_to_math_expert` to sum the numbers.
5. The math agent runs `add` and `multiply` as needed and returns the result.
6. The supervisor assembles and returns the final response.

<Tip>
  By default, `create_supervisor` uses `output_mode="last_message"`, which adds only the final message from each agent to the shared conversation history. Set `output_mode="full_history"` if you want the complete message trace from each agent included.
</Tip>

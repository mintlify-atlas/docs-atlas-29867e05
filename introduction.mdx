LangGraph Supervisor is a Python library for creating **hierarchical multi-agent systems** built on top of [LangGraph](https://github.com/langchain-ai/langgraph). It provides a central supervisor agent that coordinates multiple specialized sub-agents, delegating tasks through a tool-based handoff mechanism.

<Note>
  We now recommend using the **supervisor pattern directly via tools** for most new projects. The tool-calling approach gives you more control over context engineering. This library is maintained for users who need its specific features or are upgrading existing code.
</Note>

## What is a supervisor?

A supervisor is a special agent that acts as the orchestration layer in a multi-agent system. Rather than each agent communicating directly with every other agent, all communication flows through the supervisor:

- The supervisor receives user input
- It decides which specialized agent is best suited for the task
- It delegates work via tool-based handoffs
- It aggregates and returns the final result

This pattern is well-suited for complex workflows that require coordination between agents with different capabilities — such as combining a research agent, a math agent, and a writing agent into a single coherent system.

## How it works

```
User Input
    │
    ▼
┌─────────────┐
│  Supervisor  │  ◄── LLM decides which agent to call
└─────┬───────┘
      │ tool call (handoff)
      ▼
┌─────────────────────────────────────────┐
│  Specialized Agents                      │
│  ┌────────────┐  ┌─────────────────┐   │
│  │ math_agent │  │ research_agent  │   │
│  └────────────┘  └─────────────────┘   │
└─────────────────────────────────────────┘
      │ result
      ▼
┌─────────────┐
│  Supervisor  │  ◄── assembles final response
└─────────────┘
      │
      ▼
Final Output
```

The supervisor uses LangGraph's `StateGraph` under the hood — every `create_supervisor()` call returns a `StateGraph` that you compile and run like any other LangGraph workflow. This means you get full access to LangGraph's streaming, persistence, and human-in-the-loop capabilities.

## Requirements

- Python >= 3.10
- `langgraph >= 1.0.2`
- `langchain-core >= 1.0.0`
